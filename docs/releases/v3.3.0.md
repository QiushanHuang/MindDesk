# MindDesk v3.3.0

## Context you can inspect

The organizing assistant now makes its input explicit. Choose the selected cards and their groups, or include directly connected neighbors as read-only context. Inspect the exact request, add your own instructions, and save the setup as a reusable workflow.

After generation, edit the preview or give feedback to request a replacement. The edited draft and feedback stay visible in the request inspector. Applying rechecks the source cards, reference context and included relationships; an old interpretation cannot be applied after those inputs change.

### What's new

- **Scoped context:** editable targets and read-only references are counted separately. Parent groups, link labels and endpoint direction are preserved. Local file contents are not read.
- **Saved workflows:** keep an action, scope and instructions together. Add, duplicate, edit or remove workflows in a draft, then Save or Cancel.
- **Feedback and revision:** revise the current preview with your own feedback. The exact request remains inspectable before, during and after generation.
- **Accurate state:** changing the action, scope or instructions retires the previous preview. Modified settings are shown as custom rather than mislabeled as a saved workflow.
- **Apply and undo:** summary notes, grouping and extracted tasks retain the existing deliberate apply step and Undo behavior. Context-only card IDs are rejected as modification targets.

The visual canvas, grouped layout, quick notes, resources, snippets and task board from 3.2 remain available. No third-party Swift dependency or unrestricted embedded terminal is added.

## Installation

- macOS 14 or later; the supplied DMG and ZIP are for Apple silicon.
- Ad-hoc signed. This release is **not notarized by Apple** and has no Developer ID signature.
- Quit MindDesk, keep a backup of your local data and replace the app in Applications. The workspace database is separate from the app bundle.
- The optional organizer needs your own installed, signed-in Codex CLI and network access. Only requesting generation sends the explicitly included context to its model service.
- Installation notes, a bilingual user guide, checksums and build/package provenance accompany the downloads.

## Verification

- Source-snapshot, scope, reference exclusion, relationship freshness, custom workflow, feedback inspection, cancellation and apply/undo behavior are covered by executable checks.
- Two actual signed-in Codex tests used fictional content under a restricted desktop PATH. Chinese instructions and an English revision both worked, and the unknown budget remained unknown.
- The real native components were rendered in light and dark appearance using synthetic data.
- Native GUI automation could not connect on the validation host, including after reconnecting. Button-by-button installed-app interaction acceptance is not claimed from these renders or tests.
- See [the acceptance record](v3.3.0-acceptance.md) and the attached integrity evidence for the checked source and package scope. Model responses remain variable; these samples are not a guarantee of every interpretation.

## 中文

### 先看清上下文，再整理

整理助手现在会明确展示输入范围：只包含选中卡片及所属分组，或把直接相连的卡片加入只读参考。发送前可以检查完整请求、补充自己的要求，并把操作、范围和指令保存成工作流。

预览返回后，可以直接编辑，也可以填写反馈重新生成。旧草稿与反馈会保留在请求检查器中。应用时会再次核对来源卡片、参考内容和相关连线；输入发生变化后，需要重新生成预览。

### 本次更新

- **范围更清楚：** 可修改卡片与只读参考分开计数，保留所属分组、连线标签和方向；不会读取原文件内容。
- **工作流可复用：** 新增、复制、编辑或移除工作流，通过 Save/Cancel 保存或取消草稿。
- **结果可修订：** 根据反馈重新生成，发送前、生成中、生成后都可检查对应请求。
- **状态更准确：** 操作、范围或指令变化后，旧预览失效；修改过的设置会显示为自定义。
- **应用可撤销：** 延续摘要、分组和任务的确认应用与撤销流程，只读参考不能变成修改目标。

保留 3.2 的画布、分组布局、快速笔记、资源、片段与任务功能。没有新增第三方 Swift 依赖或不受限的内置终端。

### 安装与验证

安装包适用于 macOS 14+ 的 M 系列 Mac。更新前退出 MindDesk 并保留数据备份，再替换“应用程序”中的 App；数据库独立保存。本包采用 ad-hoc 签名，未经过 Apple 公证。

实际 Codex 验证只使用虚构内容，已覆盖中文指令、只读参考和英文反馈重生成。界面预览来自真实原生组件。验证机器的 GUI 自动化连接不可用，因此不把组件渲染与单元测试当作已安装 App 的逐项点击验收。详见[验收记录](v3.3.0-acceptance.md)。
