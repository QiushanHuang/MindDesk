# MindDesk v3.4.0

A clearer workspace with an optional, file-based Workweft canvas bridge.

- Home, workspace navigation, resources, snippets, tasks, quick notes, settings and the canvas rail use a simpler hierarchy. Common actions remain visible; other actions are grouped in menus. Optional explanations are available through accessible information controls.
- New tasks are saved only when confirmed; cancelling the editor leaves no task. Unavailable resources can be reconnected directly from their preview, with file/folder type checks.
- With a workspace selected, **Workbench → Workweft Canvas Bridge…** previews a local bridge JSON package. Review cards, links and conflicts before applying. Linked Workweft text is read-only in MindDesk; local notes, positions and grouping can be edited and exported back to JSON. This is explicit file exchange, not live synchronization of resource, snippet or task libraries.
- Undo Last Import is available only while the bridge window remains open and the imported canvas is unchanged. Deleting a linked card hides it on the shared canvas.
- **Manifest limitation:** portable MindDesk JSON cannot preserve paired Workweft canvases or their pairing state. If such canvases exist, a workspace export warns and requires an explicit choice before excluding them. Export their graphs through the bridge and keep a raw MindDesk database backup to preserve pairing state. Global Library Only remains available.
- Destructive workspace/resource/snippet operations retain their impact confirmations. Running a command still requires confirmation. The optional Codex organizer still sends the included context only when a preview is requested.
- The release bundle includes the macOS Automation usage description for user-initiated Terminal and Finder alias actions.

## Installation

The DMG and ZIP target Apple silicon Macs running macOS 14 or later. Version `3.4.0`, build `30400`. Quit MindDesk and keep a raw database backup before replacing the app in Applications. This release adds an optional canvas field for the bridge and may migrate the local store; do not assume an older app can reopen a migrated store. Restore the pre-update backup if rolling back.

The packages are **ad-hoc signed and not Apple-notarized**. If macOS blocks the app, confirm the download source before using System Settings → Privacy & Security → Open Anyway. Checksums, the bilingual guide and build provenance are included with the downloads.

## Verification

- Debug and Release suites, bridge merge and ownership checks, explicit Manifest exclusion tests, and native component previews are run as release checks.
- An isolated copy of an existing pre-update store opened with the new schema; SQLite integrity and all original model-table rows and columns were compared. The original store was not used for this migration test.
- The UI was checked with synthetic data in light and dark appearances, including narrow layouts, task creation/cancellation, command and deletion confirmations, and bridge review. Accessibility labels were inspected; this is not a complete manual VoiceOver audit.
- The packager builds from a clean recorded source commit and verifies the app signature, ZIP extraction, read-only DMG contents, checksums and provenance. The release is not notarized. The optional live-model and actual cross-app round-trip tests require explicit fixtures and were not repeated for this release.

## 中文更新说明

本版本精简工作区界面，并加入可选的 Workweft 文件画布桥接。

- 首页、工作区导航、资源、片段、任务、快速笔记、设置和画布侧栏调整了视觉层级。常用操作保持可见，其他操作集中到菜单；补充说明可通过带可访问名称的信息控件查看。
- 新任务在保存时创建，取消不会留下任务。失效资源可从预览页直接重新关联，并保留文件和文件夹类型校验。
- 选中工作区后，通过 **Workbench → Workweft Canvas Bridge…** 预览本地桥接 JSON；检查卡片、连线并解决冲突后再应用。Workweft 关联文字在 MindDesk 中只读，本地笔记、位置与分组可调整并导出 JSON。这是显式文件交换，不会实时同步资源、片段或任务库。
- 导入撤销仅在桥接窗口保持打开且导入画布未再次修改时可用。删除关联卡片会使其在共享画布中隐藏。
- **Manifest 限制：** MindDesk 便携 JSON 不能保存 Workweft 配对画布及配对状态。存在配对画布时，导出工作区前会明确提示，并要求用户确认排除；画布图可通过桥接单独导出，配对状态需要原始数据库备份。Global Library Only 仍可导出。
- 删除工作区、资源或片段前继续显示影响确认；运行命令前仍需确认。Codex 整理助手仅在请求预览时发送明确包含的上下文。
- 发布包补充 macOS 自动化权限用途说明，用于用户主动发起的终端与 Finder 别名操作。

### 安装

安装包适用于 macOS 14 及以上的 Apple 芯片 Mac，版本 `3.4.0`，构建号 `30400`。替换“应用程序”中的 App 前，请退出 MindDesk 并保留原始数据库备份。本版本为桥接增加了可选画布字段，可能迁移本地数据库；不要假定旧版能直接打开升级后的数据库，回退时请恢复更新前备份。

本包采用 **ad-hoc 签名，未经过 Apple 公证**。若 macOS 阻止打开，请先确认下载来源，再前往“系统设置 → 隐私与安全性 → 仍要打开”。附件包含校验和、中英操作指南与构建来源记录。

### 验证边界

发布检查包括 Debug/Release 测试、桥接合并与归属检查、Manifest 排除回归和原生组件预览。旧版实际数据库的独立副本已验证可打开，SQLite 完整性及原有模型表的行和列逐项一致。界面使用合成数据检查了明暗、窄布局、任务保存与取消、命令和删除确认以及桥接预览；已检查辅助功能名称，但尚未逐屏人工验收 VoiceOver。离屏渲染可能出现 SwiftUI 布局或 SceneStorage 告警。可选联网模型和真实跨应用往返测试本次未重复执行。
