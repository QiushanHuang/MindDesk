# MindDesk v3.3.1

## Existing workflow polish

This patch improves the canvas, task board, resource lists, snippets and quick notes without adding new features.

- Resource lists adapt to narrower windows, with paths, status and workspace links below the name. Snippet buttons wrap when needed, while Home cards give titles and paths more room.
- Task titles and details use separate lines. The panel adapts to available space, keeps its reopen control visible and responds immediately when a divider drag reverses at a boundary or the window is resized.
- Quick note has a clearer writing area and flexible height for content and error messages.
- Repeated actions restart their feedback timer. An older callback cannot dismiss a newer message, and leaving a card cancels pending feedback.
- Search filters before sorting and skips unrelated snippet text. Canvas geometry caching retains recently used entries when full.
- Canvas cards and frames keep consistent coordinates after zoom and pan gestures. The tool rail fits its width, and permitted connection animations remain visible at low zoom without phase jumps.
- Panel, snippet-expansion and feedback animations respect macOS Reduce Motion. Icon buttons and editors have clearer accessibility labels.

## Installation

The DMG and ZIP are for Apple silicon Macs running macOS 14 or later. Version `3.3.1`, build `30304`.

Quit MindDesk, keep your normal data backup and replace the app in Applications. The database is stored separately from the application bundle. This update does not change the database schema or move original files.

The packages are **ad-hoc signed, not Apple-notarized**. Installation instructions, the bilingual user guide, SHA-256 checksums and build/package provenance are included with the downloads. The optional organizer continues to use your own installed, signed-in Codex CLI when you request a preview.

## Verification

- Debug and Release each covered a 742-case suite on the unchanged application implementation, with no failures and opt-in skips. Two live-model integrations are opt-in; the documentation renderer is also opt-in and was exercised separately with synthetic data.
- Regression checks cover feedback expiration, divider boundaries and window resizing, geometry cache retention, and search equivalence across 2,048 resources and 1,024 snippets.
- Native component previews cover light/dark appearance, narrow resource and snippet layouts, collapsed and short task panels, and quick-note sizing.
- The preceding local build was installed and reopened successfully; its About panel and executable identity were checked. This establishes installation and startup, not exhaustive gesture acceptance.
- Packages are built from the tagged source using the repository's packaging script, with signed-bundle manifests, ZIP extraction checks, read-only DMG verification and checksums. See the attached provenance files and [acceptance record](https://github.com/QiushanHuang/MindDesk/blob/v3.3.1/docs/releases/v3.3.1-acceptance.md).

No specific FPS, CPU or power improvement is claimed. The organizer protocol and behavior are unchanged; live model calls were not repeated for this patch.

## 中文更新说明

本补丁优化画布、任务、资源列表、片段和快速笔记的现有操作，不增加新功能。

- 窄资源列表分层显示名称、路径、状态和工作区链接；片段按钮按需换行，首页卡片为标题和路径留出更多空间。
- 任务标题与说明分行，面板适应可用宽高；折叠后保留展开入口，分隔线到达边界后反向拖动及调整窗口大小时及时响应。
- 快速笔记的编辑区边界更清晰，弹性高度为正文和错误信息留出空间。
- 连续操作会重新开始提示计时，旧回调不会清除新反馈；离开卡片后取消待执行提示。
- 搜索先筛选再排序，跳过无关工作区的片段正文；画布缓存满额时保留最近使用的几何结果。
- 缩放和平移结束后，卡片与分组框保持一致坐标。工具栏适应实际宽度，允许播放的连线动画在低缩放下继续显示，避免相位跳变。
- 面板、片段展开和操作反馈动画遵循“减少动态效果”，图标按钮与输入区补充了可访问名称。

### 安装

安装包适用于 macOS 14+ 的 Apple 芯片 Mac，版本 `3.3.1`，构建号 `30304`。退出 MindDesk 并保留常规数据备份后，将 App 替换到“应用程序”。数据库独立于 App 保存，本次没有数据库结构变更，也不移动原文件。

安装包采用 **ad-hoc 签名，未经过 Apple 公证**。附件包含 DMG、ZIP、中英说明、SHA-256 校验和及构建来源记录。可选整理助手继续使用用户自己的 Codex CLI，仅在请求生成预览时调用。

### 验证边界

应用实现沿用已通过 Debug/Release 测试和 CI 的源码，测试集合共 742 项；联网模型测试按需启用，本补丁没有重复发起模型请求。反馈计时、分栏边界、窗口缩放、缓存保留和搜索等价性有回归覆盖，明暗和窄布局预览均使用虚构数据。
