# Canvas 恢复版（本机更新）

## 恢复的体验

- 画布回到 v3.1.1 的显示与手势实现，撤下后续的 AppKit 承载层及翻转变换。
- 恢复原来的浅色细网格（0.5 点、低对比度），不再使用新版粗黑线背景。
- 保留整理助手、快速笔记和搜索分类，不改动已有用户数据。

## 修复的操作

- 自动排列以整个分组为单位移动，保留框、嵌套框和卡片之间的相对位置。
- 包含锁定卡片的分组整体保留原位，避免只移动框而留下卡片。
- 拖动外层框时递归带上嵌套框及其关联卡片。
- 自动排列后适配视野；整次排列可以撤销；共同平移的连线保留手动弯曲位置。

## 验证范围

- 三个新增回归场景先复现失败，再通过修复：嵌套分组排列、锁定子卡片、嵌套框拖动。
- 相关测试合计 370 项，0 失败；其中 1 项外部 Codex 实测为主动启用测试，本轮跳过。
- S0 策略自检通过。
- Release 构建成功；本机已安装 3.1.1（30103），安装包签名完整性检查通过。
- 不以自动化测试替代全屏实机拖动、缩放和文字方向的视觉验收。本轮桌面控制连接失败，无法完成该项实机验证。

## 保存与后续

- 恢复工作保存在 `codex/canvas-recovery`，原动效引擎分支与未提交工作原样保留。
- 本轮不提交、不推送、不创建公开发行版。
- 原 30102 App 保留于 `dist/local-updates/canvas-recovery-20260919.iMkvGx/MindDesk-previous-30102.app`（相对主仓库）；没有删除用户数据。旧进程未被强制终止，需要退出并重新打开 MindDesk 才能使用恢复版。
- 后续引擎设计应保持一个统一的世界坐标系：卡片、框、连线共用相机变换；分组操作共享成员关系；先通过交互验收，再引入新的渲染承载层。
