# MindDesk v3.1.1

MindDesk v3.1.1 is a focused Canvas performance update. Zooming, moving the background, and dragging cards should respond more evenly, including on smaller Canvases. The visual style stays the same: connection glow continues to animate and cards keep their full detail while you work.

## What changed

### Smoother Canvas movement

- Trackpad zoom and background panning now follow the display refresh instead of asking the whole Canvas to redraw for every tiny input event.
- Moving and resizing cards, drawing a selection box, and adjusting connections use the same smoother update path.
- The exact final position and zoom are still saved when the gesture ends.

### Less repeated work

Cards and connections that have not changed are now reused while the view moves around them. This matters on large project maps, but it also fixes the smaller stutters that could appear with fewer than 20 cards.

The Canvas also avoids producing a new delayed task for every scroll event. Old scroll work can no longer interrupt a newer gesture.

### Visual quality stays intact

This update does not switch to simplified cards during movement. Text, card details, connection glow, arrows, selection states, resize handles, and connection controls remain visible.

Lines, arrows, handles, and click areas now keep a consistent on-screen size across large zoom changes. Extreme zooming also has a drawing-size limit, preventing a temporary oversized surface from causing another pause.

## Bugs fixed

- Background panning, zooming, and card dragging could repeatedly rebuild stable Canvas content.
- Connection control points and click detection could briefly use different coordinate systems during a live zoom or pan.
- Connection lines, arrows, and resize handles could become too large during an extreme zoom and then jump back when the gesture ended.
- A large zoom-out could create a drawing surface far bigger than the visible window.
- Delayed work from an earlier scroll gesture could finish during a newer gesture.
- Two older source checks still expected the previous Canvas lookup path after the new cache was introduced.

## What stays the same

- Existing workspaces, cards, links, tasks, resources, snippets, notes, and layout data do not need migration.
- Files remain in Finder where they already are.
- The privacy and workspace-safety changes from v3.1.0 remain in place.
- MindDesk still requires macOS 14 or newer.

## Installation

1. Download `MindDesk-v3.1.1-macOS-arm64-adhoc.dmg` or the matching ZIP from this GitHub Release.
2. Open the DMG and drag MindDesk.app into Applications.
3. Launch MindDesk from Applications.
4. This package is ad-hoc signed and is not Apple-notarized. If macOS blocks the first launch, confirm the download came from the official MindDesk repository, then use System Settings > Privacy & Security > Open Anyway. You can also Control-click MindDesk in Finder and choose Open.

## Verification

Canvas behavior passed 335 focused tests. The complete app then passed 696 Debug tests and 696 Release tests with no failures. A separate Release build also completed successfully.

The release package is checked after building: the app inside both the ZIP and DMG is matched against recorded manifests, and the published proof files include SHA-256 checksums.

## Known limitation

Automated launch testing confirmed that the app opens and enters a workspace. The macOS accessibility connection used by the test tool stopped responding after entering Canvas, so the final subjective trackpad feel was not measured by automation. The gesture behavior, saved final state, coordinates, animations, and visual-detail rules are covered by automated tests.

## 中文说明

MindDesk v3.1.1 主要解决 Canvas 操作时的卡顿。缩放、拖动背景、移动卡片现在会更连贯，小于 20 张卡片的 Canvas 也能受益。视觉效果没有为了性能而缩水，连线发光会继续播放，卡片内容也不会在操作时变成简化版本。

### 本次更新

- 触控板缩放和背景拖动会跟随屏幕刷新节奏更新，不再为每一个细小输入重复刷新整张 Canvas。
- 移动与缩放卡片、框选、调整连线控制点也使用相同的顺滑更新方式。
- 手势结束时仍会保存精确的最终位置与缩放比例。
- 没有变化的卡片和连线会在移动视角时直接复用，减少重复计算。
- 连线、箭头、控制点、缩放手柄和点击区域在大幅缩放时保持稳定尺寸。
- 极端缩放加入绘制尺寸上限，避免临时生成远大于窗口的画面。

### 修复的问题

- 修复缩放、背景拖动和卡片拖动时反复重建稳定内容造成的短暂停顿。
- 修复实时缩放或移动期间，连线控制点与点击检测偶尔使用不同坐标的问题。
- 修复大幅缩放时连线、箭头和手柄突然变大，并在松手后跳回原尺寸的问题。
- 修复大幅缩小时可能创建过大绘制区域的问题。
- 修复旧滚轮手势留下的延迟操作干扰新手势的问题。
- 修复两项旧测试仍在检查已经替换的 Canvas 查询方式的问题。

### 没有改变的内容

- 工作区、卡片、连线、任务、资源、Snippet、笔记和布局不需要迁移。
- Finder 中的原文件不会被移动或修改。
- v3.1.0 的隐私保护和工作区切换安全规则继续保留。
- 本版本仍要求 macOS 14 或更高版本。

### 安装

下载 `MindDesk-v3.1.1-macOS-arm64-adhoc.dmg` 或对应 ZIP。打开 DMG 后把 MindDesk.app 拖进 Applications 即可。

安装包使用 ad-hoc 签名，没有经过 Apple 公证。如果 macOS 首次阻止打开，请先确认安装包来自 MindDesk 官方仓库，再前往“系统设置 > 隐私与安全性”选择“仍要打开”。也可以在 Finder 中按住 Control 点击 MindDesk，再选择“打开”。

### 验证记录

Canvas 相关测试 335 项全部通过。完整 Debug 和 Release 测试各 696 项，均为 0 失败，Release 产品构建也已成功完成。ZIP 和 DMG 内的 App 会再次与发布记录核对，并附带 SHA-256 校验文件。

### 已知限制

自动化测试确认应用可以启动并进入工作区，但测试工具进入 Canvas 后失去了 macOS 辅助功能连接，因此没有自动记录真实触控板的主观手感。手势结果、最终保存位置、坐标、动画和内容细节均已有自动测试覆盖。
