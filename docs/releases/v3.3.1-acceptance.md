# MindDesk v3.3.1 acceptance

This patch packages the application implementation from `1b88815507ce75bfb3f77380fbe8b00c9893b0a2`. Release preparation changes version metadata and documentation only. The source commit used for each package is recorded in its attached `build-provenance.json` and `verified-artifacts.json`.

## Application evidence

- [Implementation CI](https://github.com/QiushanHuang/MindDesk/actions/runs/37014563117) passed the private package policy, independent Release build, Debug/Release suites, release-script self-tests, package smoke verification and artifact checks.
- Local Debug validation with documentation previews enabled ran 302 application tests and 440 core tests: no failures, 2 live-model tests skipped. Local Release validation ran the same 742 cases: no failures, 3 opt-in skips (the renderer and 2 live-model tests).
- Four deterministic feedback tests cover repeated identical messages, message replacement, disappearing/reappearing cards and object release. The two stale-callback failures were reproduced before the fix.
- Six divider tests cover immediate reversal at both boundaries, resized-window rebasing, narrow widths, ordinary movement and geometry bounds.
- Search equivalence tests compare against the previous pipeline across 2,048 resources, 1,024 snippets, scopes and queries. Cache tests verify retention of recently used geometry and correct invalidation after edits.
- Synthetic native previews cover light/dark appearance, 220/280 pt cards, a 340 pt snippet list card, a 520 pt task panel, resource lists, the collapsed task bar and quick-note sizing.
- The preceding `3.3.0 (30303)` local optimization build was installed with a preserved previous app, reopened, and checked through its About panel and process identity. The installer did not modify the personal database or preferences.

## Package verification

The release package uses version `3.3.1`, build `30304`, Apple silicon, macOS 14+, and ad-hoc signing. The explicit build number keeps it above the preceding local optimization build.

```sh
./script/verify_release_metadata.sh
./script/verify_release_worktree.sh
BUILD_NUMBER=30304 RELEASE_PLATFORM_SUFFIX=macOS-arm64 ./script/package_release.sh --mode adhoc --allow-adhoc
./script/verify_release_artifacts.sh \
  --artifact-dir dist/release/MindDesk-v3.3.1-macOS-arm64-adhoc/artifacts \
  --source-head "$(git rev-parse HEAD)" --version 3.3.1 --suffix macOS-arm64 --mode adhoc
```

The packager requires a clean source tree, builds in a fresh private directory, verifies the pre-sign and final bundle manifests, extracts and checks the ZIP, mounts the DMG read-only for validation, and emits checksums with source-bound provenance. Uploaded asset digests must match the verified local files before publication.

This is not an Apple-notarized release. Startup checks and component renders do not establish exhaustive gesture acceptance or a measured FPS, CPU or energy improvement. No additional live-model request is required for the unchanged organizer.
