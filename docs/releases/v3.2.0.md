# MindDesk v3.2.0

A clearer project desk, with an organizing assistant you can preview before applying.

[English](#updates) · [简体中文](#中文更新说明)

## Updates

### Capture and find
- Add quick notes with an optional title; save with ⌘ Return.
- Filter Quick Open results by workspace, resource, snippet or web card.

### Turn cards into a plan
- Summarize selected cards into a new note.
- Suggest named groups and arrange selected cards in frames.
- Extract tasks with references back to the source cards.
- Edit the preview before applying; undo an applied result.
- Reuse your signed-in local Codex CLI. Selected card text is sent to its model service when you request a preview. This optional feature requires network access and your own Codex account.

### Canvas fixes
- Use the established canvas rendering and gesture path instead of the experimental retained rendering layer associated with flipped text and dragging regressions.
- Restore the subtle, thin background grid.
- Keep nested frames and cards together during dragging and Auto Arrange.
- Leave an entire group in place when it contains a locked card.
- Fit the view after automatic arrangement and support undoing it.

### Preview startup fix
Desktop launches now include the standard runtime search paths needed by npm-installed Codex. This fixes the reproduced status 127 failure caused by missing Node lookup. The error message now distinguishes a missing runtime from sign-in troubleshooting.

### New identity and guides
A connected-card M logo, matching app icon, and rewritten English/Chinese README put everyday workflows first. Language badges jump within the README; the operation guide covers installation, capture, canvas, organization, tasks and backups.

## Installation

Requires macOS 14+; supplied DMG/ZIP: Apple silicon (arm64).
Open the DMG and drag MindDesk.app to Applications. Quit the old app before replacing it. Export a Manifest and keep a backup before updating. This release is ad-hoc signed and not Apple-notarized. If blocked, verify the source, then use System Settings → Privacy & Security → Open Anyway.

See the [operation guide](../user-manual.md) for the optional Codex CLI setup and troubleshooting. The release assets include both DMG and ZIP installers, bilingual instructions and checksums.

## Verification

Focused canvas/grouping and organizer regression tests passed during development, including a real synthetic Codex preview under a desktop-style minimal PATH. The release is built from the merged source revision, with archive/bundle integrity checked by the release packaging process. Full-screen visual smoothness is not a measured performance guarantee.

Manual connection bends may need adjustment after AI grouping moves their cards. Original files remain in place; failed previews do not apply changes.

## 中文更新说明

### 更快记录，更快找到
- 快速笔记支持不填标题，按 ⌘ Return 即可保存。
- Quick Open 增加类型筛选，快速查找工作区、资源、片段和网页卡片。

### 将卡片整理成可继续的工作
- 将选中卡片汇总为新的摘要笔记。
- 生成分组建议，按主题整理进命名框。
- 提取工作区任务，并保留来源卡片引用。
- 先预览、修改，再应用；应用后支持撤销。
- 复用本机已登录的 Codex CLI。请求预览时，所选卡片文字会发送至其模型服务；这项可选功能需要联网和自己的 Codex 账号。

### 画布修复
- 恢复既有画布显示与手势实现，撤下出现文字翻转和拖动异常的实验性承载层。
- 恢复低对比度的细网格背景。
- 拖动和自动排列时，嵌套框与内部卡片保持整体移动。
- 包含锁定卡片的组整体留在原位。
- 自动排列后适配视野，并支持撤销整次排列。

### 修复预览启动失败
补齐桌面启动时 Codex 所需的常见运行环境路径，修复因找不到 Node 而返回 127 的问题；相关提示不再将运行环境缺失误报为登录问题。

### 新标识与中英指南
新增“相连卡片组成 M”的 Logo 和配套 App 图标。README 优先介绍使用场景、现有工作方式的痛点及实际收益；语言徽标在同一页面内跳转。操作指南涵盖安装、记录、画布、整理助手、任务与备份。

### 安装与使用
需要 macOS 14+，本次 DMG/ZIP 适用于 M 系列 Mac。打开 DMG 后将 App 拖入“应用程序”，更新前退出旧版。建议先导出 Manifest 并保留备份。本包采用 ad-hoc 签名，未经过 Apple 公证；若首次被阻止，请核对来源后前往“系统设置 → 隐私与安全性 → 仍要打开”。

画布分组与整理助手已有针对性回归测试，桌面精简环境下的真实测试预览已成功生成。全屏流畅度仍需要实际设备体验，不提供未测量的帧率保证。AI 分组后，手动弯曲过的连线可能需要调整。原文件保留原位，预览失败不会应用更改。
