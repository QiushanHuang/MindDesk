# MindDesk v3.1.0

MindDesk v3.1.0 is a private, manual Canvas release. It removes the retired AI review and embedded terminal features, makes workspace switching safer, and checks a card's current ownership before opening it from Quick Open.

## What changed

### One clear, private product

MindDesk is now focused on workspaces, visual Canvas maps, tasks, resources, snippets, notes, and local project relationships. The old Canvas Review, Agent Review, Proposal Review, Canvas Codex, and embedded terminal entry points have been removed from the current app.

MindDesk does not start an AI helper, build an AI context package, or send Canvas content to a model through those retired features. Ordinary Manifest import and export remains available for moving your own MindDesk data.

### Safer workspace and Canvas switching

- Each window keeps its own current workspace and Canvas work.
- Moving from workspace A to workspace B cancels old work from A before B takes over the screen.
- Repeating the same action reuses the current result instead of starting duplicate work.
- When a workspace has no Primary Canvas, MindDesk prepares one in an isolated save path so unrelated unsaved work is not rolled back or mixed into the operation.
- If Primary Canvas data is missing, duplicated, or unavailable, MindDesk stops safely and shows a clear state instead of choosing a record at random.
- Overview, Tasks, Resources, and Snippets remain available while Canvas is checking or unavailable.

### Quick Open opens the right card

Quick Open requests now carry the workspace, Canvas, and card identity together. Before MindDesk selects a card, it checks the current data again.

This fixes several frustrating edge cases: an old request arriving after a workspace switch, a card moving to another Canvas, a card being deleted before the request finishes, or the same request being replayed. In all of those cases, MindDesk now declines the stale request instead of opening the wrong card.

### Clearer recovery

Canvas can now show distinct checking, preparing, missing, duplicate, and unavailable states. Try Again starts one fresh attempt when that action is appropriate. It does not create a retry loop in the background.

## Bugs fixed

- A delayed Canvas result could outlive the workspace that started it and update the wrong window.
- Old background work was not always detached and cancelled at the exact point where a new workspace took over.
- Repeated focus or binding calls could do unnecessary work and change state even when nothing had changed.
- Preparing a missing Canvas could share a save context with unrelated scene edits.
- A stale Quick Open request could point at a moved, deleted, or no-longer-owned card.
- Ambiguous Primary Canvas records could be treated too optimistically instead of stopping safely.
- Historical review-package files could reach retired import behavior. They are now rejected without changing current app data.
- Cards that were still rendering could be reported as deleted before the view was ready.
- Import and validation errors could include local paths, URLs, or command fragments that should not appear in ordinary status text.
- Resetting settings could leave old Agent, Codex, and Proposal Review preferences behind.
- Help could reopen a page for a feature that no longer exists.
- Release outputs were not fully tied together. The app, ZIP, DMG, build record, bundle manifests, and checksums now have an exact verified relationship.

## Privacy and data

- Files and folders stay in Finder where they already are.
- Removing a MindDesk reference does not delete, move, or rename the original file.
- Opening files, URLs, Finder locations, imports, and exports still requires a direct user action.
- Manifest files may contain paths, notes, snippets, tasks, and Canvas text. They do not contain macOS security-scoped bookmark authorization data.
- The retired Canvas Review feature does not send Canvas content to an AI service because the feature is no longer present.
- Historical `.mip.json`, Proposal Envelope, and Validation Report files are recognized but cannot be imported as ordinary Manifest data. Rejection happens before records are written or an external action is opened.

## Installation

MindDesk requires macOS 14 or newer.

1. Download the DMG from the v3.1.0 GitHub Release.
2. Open the DMG and drag MindDesk.app into Applications.
3. Launch MindDesk from Applications.
4. This build is ad-hoc signed and is not Apple-notarized. If macOS blocks the first launch, confirm the package came from the official MindDesk repository, then use System Settings > Privacy & Security > Open Anyway. You can also Control-click MindDesk in Finder and choose Open.

## Download files

The GitHub Release includes a DMG installer, a ZIP archive, installation notes, release notes, and SHA-256 checksums. The checksum file lets you confirm that a download is complete and unchanged.

## Verification

The complete app passed 666 Debug tests and 666 Release tests with no failures. A separate Release build was checked against the source policy. The final ZIP and DMG were opened independently, their app bundles were compared with the recorded manifests, and every published proof file received a SHA-256 checksum.

## 中文说明

MindDesk v3.1.0 现在专注于一件事：在本地用工作区、Canvas、任务、资源、Snippet 和笔记整理项目。旧的 Canvas Review、Agent Review、Proposal Review、Canvas Codex 和内嵌终端入口已经从当前产品中移除。

### 本次主要更新

- 每个窗口独立管理当前工作区。切换项目时，旧项目尚未完成的 Canvas 操作会先取消，不会再覆盖新项目的画面。
- 工作区缺少主 Canvas 时，MindDesk 会安全地准备一个；数据重复或不可用时会停止并说明原因，不会随便选一个继续。
- Canvas 正在检查或暂时不可用时，Overview、Tasks、Resources 和 Snippets 仍可正常使用。
- Quick Open 在打开卡片前会重新确认卡片仍属于当前工作区和 Canvas。卡片已移动、删除，或请求已经过期时，不会误开其他卡片。
- Try Again 每次只发起一个新的检查，不会在后台不断重试。

### 修复的问题

- 修复切换工作区后，旧 Canvas 结果延迟返回并覆盖当前窗口的问题。
- 修复重复聚焦、重复绑定或重复重试造成多余状态变化的问题。
- 修复创建缺失 Canvas 时可能与其他尚未保存的编辑共用保存状态的问题。
- 修复旧的 Quick Open 请求在卡片移动或删除后仍可能选中错误内容的问题。
- 修复主 Canvas 数据重复时仍可能继续使用其中一条记录的问题。
- 修复历史审阅包仍可能进入旧流程的问题。现在会直接拒绝，并且不会修改当前数据。
- 修复卡片还在渲染时被过早判断为“已删除”的问题。
- 修复导入或检查错误可能在普通状态提示中显示本地路径、网址或命令片段的问题。
- 修复重置设置后仍可能留下旧 Agent、Codex 和 Proposal Review 选项的问题。
- 修复 Help 可能重新打开已移除功能页面的问题。
- 修复发布包之间缺少完整对应关系的问题。现在 ZIP、DMG、App、构建记录和校验文件会一起核对。

### 隐私说明

MindDesk 不会通过已下线的审阅功能启动 AI 助手、生成 AI 上下文包或把 Canvas 内容交给模型。旧版 `.mip.json`、Proposal Envelope 和 Validation Report 会被识别并安全拒绝，不会作为普通 Manifest 写入数据。真实文件仍保留在 Finder 原位置，删除 MindDesk 中的引用不会删除、移动或重命名原文件。

### 安装说明

本版本支持 macOS 14 及以上系统。v3.1.0 使用 ad-hoc 签名，没有经过 Apple 公证。如果 macOS 首次阻止打开，请先确认安装包来自 MindDesk 官方仓库，再前往“系统设置 > 隐私与安全性”选择“仍要打开”。

GitHub Release 同时提供 DMG、ZIP、安装说明、发行说明和 SHA-256 校验文件。可以使用校验文件确认下载内容完整且没有被修改。

### 已知限制

- 当前版本不提供 Canvas AI 审阅、Proposal Review 或内嵌 Codex 终端。
- MindDesk 不提供自己的云同步或多人协作服务。数据同步效果取决于你使用的系统备份、文件服务或同步工具。
- 如果一个工作区已经存在多个冲突 Canvas，MindDesk 会暂停 Canvas 编辑以保护数据，不会自动合并或删除记录。
- 安装包没有经过 Apple 公证，首次启动可能需要手动允许。
