# MindDesk identity

Connected cards form an M above a desk line. The two paper cards represent reference material; the mint card turns that material into a next step.

- Deep blue: #132D46
- Paper: #F3F5EE
- Mint: #70D7C7
- Vector master: minddesk-logo.svg
- App raster: ../../Sources/MindDesk/Resources/AppIcon.png
- Maintainer: [Qiushan (QiushanHuang)](https://github.com/QiushanHuang)

Render a PNG with `swift script/render_brand.swift OUTPUT.png 1024` from the repository root. Build the macOS icon from the standard 16–512 point iconset sizes, including 2× variants, using iconutil. Keep the mark square with its transparent outer margin.
